1 Definição de dados em SQL
     SQL utiliza os termos tabela, linha e coluna para relação, tupla e atri-
buto, respectivamente. Os comandos SQL para definição de dados (DDL
– Data Definition Language) são usados para estruturar o banco de dados,
suas tabelas e visões (do inglês, views), tabelas virtuais que exibem dados
de uma ou mais tabelas reais, sem armazená-la fisicamente (Ramakrish-
nan e Gehrke, 2011). Esses comandos são: CREATE, ALTER e DROP.


1.1 Comando CREATE

     O comando CREATE pode ser utilizado para criação de objetos den-
tro do banco de dados, como esquemas de banco de dados, tabelas,
domínios (tipos de dados), restrições de integridade (como chaves pri-
márias e estrangeiras) e visões.


1.1.1 Comando CREATE TABLE

     O comando CREATE TABLE permite criar tabelas no banco de dados.
Dentro de cada tabela, deve-se especificar os atributos (colunas) e as
restrições. Cada atributo deve possuir um nome, um tipo de dado para
especificar seu domínio de valores e, possivelmente, algumas restrições.
As restrições de chave, restrição de valores nulos de atributos, integri-
dade de entidade e integridade referencial são então especificadas (Rama-
krishnan e Gehrke, 2011). Observe a criação das tabelas DEPARTAMENTO
e FUNCIONARIO, conforme apresentado a seguir, adaptado de Elmasri e
Navathe (2018):

    Os tipos de dados disponíveis em SQL (Elmasri e Navathe, 2018) são:

    • Cadeias de caracteres de comprimento fixo ou variável. O tipo
         CHAR(n) representa uma cadeia de caracteres de comprimento fixo
         n. Se um atributo possui tipo CHAR(n), então, em qualquer linha, o
         componente deste atributo será uma cadeia de n caracteres. VAR-
         CHAR(n) representa cadeias de até n caracteres. Componentes de
         um atributo deste tipo são cadeias de 0 a n caracteres.

    • Cadeias de bits de comprimento fixo ou variável são análogas às
         cadeias de caracteres de comprimento fixo e variável; entretanto, os
         seus valores são cadeias de bits ao invés de caracteres. O tipo BIT(n)
         representa cadeias de bits de comprimento n, enquanto BIT VARYIN-
         G(n) representa cadeias de bits de comprimento de 0 até n.

    • O tipo INT ou INTEGER (estes nomes são sinônimos) representam
         valores inteiros típicos.

    • Número de ponto flutuante pode ser representado em uma varie-
         dade de formas. Podemos usar o tipo FLOAT ou REAL (estes nomes
         são sinônimos) para números de ponto flutuante típico. Uma pre-
         cisão mais alta pode ser obtida com o tipo DOUBLE PRECISION.
         SQL também possui tipos que são números reais com um ponto
         decimal fixo. Por exemplo, DECIMAL(n, d) permite valores que con-
         sistem em n dígitos decimais, com o ponto decimal posicionado
         a d dígitos a partir da direita. Então, 1234.56 é um possível valor
         do tipo DECIMAL(6, 2).

    • Datas e horas podem ser representadas pelos tipos DATE e TIME,
         respectivamente.

    SQL permite que os valores sejam NULL (nulo). Um valor nulo indica
que o valor é indefinido ou é um campo opcional cujo valor é desprezível.
Uma restrição NOT NULL pode ser especificada para evitar que um dado
atributo possa assumir o valor NULL. Tal restrição deve ser aplicada para

2 Consultas em SQL
    SQL possui um comando básico para realizar consultas no banco de
dados, o comando SELECT (Elmasri e Navathe, 2018). Uma consulta SQL
segue a estrutura, conforme é apresentado no exemplo 6.

                              Exemplo 6 – Estrutura do comando SELECT


                                  SELECT <lista de colunas>
                                  FROM <lista de tabelas>
                                  WHERE <condição>;


    No exemplo 6, temos o comando SELECT para realizar consultas no
banco de dados. A estrutura tem três partes, a primeira parte é SELECT
e uma lista de colunas que serão apresentadas como resultado da


SQL – Uma linguagem de banco de dados                                                    81
consulta. A segunda parte é a cláusula FROM e uma lista de tabelas que
são as relações a serem processadas para responder à consulta. A ter-
ceira parte consiste na cláusula WHERE e uma condição lógica que iden-
tifica as tuplas a serem obtidas na consulta.

     Onde:

     • <lista de atributos> é uma lista de nomes de atributos
        cujos valores serão obtidos pela consulta.

     • <lista de tabelas> é uma lista dos nomes das relações reque-
        ridas para processar a consulta.

     • <condição> é uma expressão lógica que identifica as tuplas a
        serem obtidas pela consulta.


2.1 Consultas simples

     Suponha a seguinte consulta: obtenha o nome e o salário dos funcio-
nários cujo salário seja maior que 3000. Um exemplo do comando SELECT
pode ser observado no exemplo 7.

                          Exemplo 7 – Comando SELECT


                         SELECT NOME, SALARIO
                         FROM FUNCIONARIO
                         WHERE SALARIO > 3000;


     Essa consulta envolve apenas a relação FUNCIONARIO listada na cláu-
sula FROM. A consulta seleciona tuplas de FUNCIONÁRIO que satisfa-
zem a condição da cláusula WHERE, então projeta o resultado sobre os
atributos NOME e SALARIO, listados na cláusula SELECT.

     Para selecionar todas as tuplas da tabela e todos os seus atributos
utilize o comando SELECT, listado no exemplo 8.

2.2 Consultas com junção de tabela

    A demonstração seguinte envolve uma consulta que utiliza o relacio-
namento entre duas tabelas. Deseja-se listar o nome dos funcionários e
os departamentos em que eles trabalham, conforme exemplo 9.

                          Exemplo 9 – Consulta com junção de duas tabelas


                     SELECT FUNCIONARIO.NOME, DEPARTAMENTO.NOME
                     FROM FUNCIONARIO, DEPARTAMENTO
                     WHERE FUNCIONARIO.NDEPTO = DEPARTAMENTO.NUMDEP;


    Na consulta apresentada no exemplo 9, a cláusula WHERE contém a
expressão FUNCIONARIO.NDEPTO = DEPARTAMENTO.NUMDEP que
é chamada condição de junção, pois combina duas tuplas: uma de FUN-
CIONARIO e outra de DEPARTAMENTO, sempre que o atributo NDEPTO
de FUNCIONARIO é igual ao atributo NUMDEP de DEPARTAMENTO.

    Em SQL, um mesmo nome pode ser usado para dois (ou mais) atri-
butos desde que eles estejam em relações diferentes. Se este é o caso,
e a consulta refere-se a dois ou mais atributos com o mesmo nome, deve-
-se qualificar o nome do atributo com o nome da relação para prevenir
ambiguidade (Elmasri e Navathe, 2018). Isso acontece por prefixar o
nome da relação com o nome do atributo para separar os dois por um
ponto. O exemplo 9 ainda apresenta esta situação por ter o atributo NOME
tanto na relação FUNCIONARIO quanto na relação DEPARTAMENTO.

2.3 Tabelas como conjuntos em SQL

    SQL não trata uma relação como um conjunto. Tuplas duplicadas
podem aparecer mais do que uma vez em uma relação ou no resultado
de uma consulta. Mas uma consulta SQL não elimina automaticamente
tuplas duplicadas nos resultados da consulta. Para obter apenas tuplas
distintas no resultado de uma consulta SQL, utiliza-se a palavra-chave
DISTINCT na cláusula SELECT (Ramakrishnan e Gehrke, 2011). Suponha
a consulta na qual deseja-se recuperar o salário de todos os emprega-
dos, observe o exemplo 12.

                             Exemplo 12 – Consulta com valores distintos


                                 SELECT DISTINCT SALARIO
                                 FROM FUNCIONARIO


    SQL possui alguns operadores de manipulação de conjuntos (Rama-
krishnan e Gehrke, 2011) tais como união (UNION), intersecção (INTER-
SECTION) e diferença (EXCEPT). Considere a consulta que necessite
listar projetos que possuem funcionários com sobrenome “Silva”, seja
como funcionário ou gerente. O próximo exemplo apresenta uma con-
sulta com o operador UNION.

                             Exemplo 13 – Consulta com operador UNION


   SELECT NUMPROJ
   FROM PROJETO P, DEPARTAMENTO D, FUNCIONARIO F
   WHERE   P.NDEPTO = D.NUMDEP AND
           D.NSUPER = F.NUMAT AND
           F.SOBRENOME = ‘Silva’
   UNION
   SELECT NPROJ AS NUMPROJ
   FROM TRABALHA_EM TE, FUNCIONARIO F
   WHERE   TE.NUMEMP = F.NUMAT AND
           F.SOBRENOME = ‘Silva’

2.4 Consultas aninhadas

     Algumas consultas requerem que valores existentes no banco de
dados sejam recuperados e usados em uma condição de seleção. Tais
consultas podem ser formuladas por meio de consultas aninhadas, como
mostra o exemplo 14.

                         Exemplo 14 – Consultas aninhadas


     SELECT DISTINCT NUMPROJ
     FROM PROJETO P
     WHERE   NUMPROJ IN (SELECT NUMPROJ
                         FROM PROJETO P, DEPARTAMENTO D, FUNCIONARIO F
                         WHERE P.NDEPTO = D.NUMDEP AND
                                D.NSUPER = F.NUMAT AND
                                F.SOBRENOME = ‘Silva’)
     OR
     NUMPROJ IN (SELECT NPROJ
                        FROM TRABALHA_EM TE, FUNCIONARIO F
                        WHERE TE.NUMEMP = F.NUMAT AND
                                F.SOBRENOME = ‘Silva’)


     Segundo Ramakrishnan e Gehrke (2011), uma consulta aninhada é
uma consulta que contém outra inserida dentro dela; essa consulta ani-
nhada é chamada de subconsulta (do inglês, subquery). O operador IN
compara um valor v com um conjunto de valores V e devolve true se v é
um dos elementos de V (Elmasri e Navathe, 2018).

2.6 Funções agregadas e agrupamento

    Por agregação, entende-se uma operação que toma uma coleção de
valores como entrada e devolve um único valor (Silberschatz, Korth e
Sudarshan, 2020). Por exemplo, a soma e a média de valores de uma
coluna. SQL, não apenas permite agregar colunas, mas também agrupar
tuplas de uma relação de acordo com algum critério, como o valor em
alguma outra coluna, e, então, agregar dentro de cada grupo. SQL ofe-
rece cinco funções agregadas que podem ser aplicadas a uma coluna:

    • SUM: a soma dos valores

    • AVG: a média dos valores

    • MIN: o valor mínimo do conjunto

    • MAX: o valor máximo do conjunto

    • COUNT: o número de valores (incluindo duplicatas, a menos que
         elas sejam explicitamente eliminadas com DISTINCT)

    Suponha uma consulta em que se deseja obter a soma dos salários,
o maior salário, o menor salário e a média salarial de todos os funcioná-
rios, como demonstra o exemplo a seguir.




SQL – Uma linguagem de banco de dados                                  87
                          Exemplo 16 – Funções de agregação


                         SELECT SUM(SALARIO), MAX(SALARIO),
                              MIN(SALARIO), AVG(SALARIO)
                         FROM FUNCIONARIO


     Em alguns casos, é útil aplicar as funções agregadas a subgrupos de
tuplas de uma relação, com base em alguns valores de atributos. Por
exemplo, deseja-se encontrar a média salarial de funcionários por depar-
tamento ou o número de empregados que trabalham por departamento.

                  Exemplo 17 – Funções de agregação com agrupamento


                         SELECT NDEPTO, COUNT(*), AVG(SALARIO)
                         FROM FUNCIONARIO
                         GROUP BY NDEPTO


     No exemplo 17, para cada número de departamento, a consulta devolve
o número de empregados computado pela função COUNT(*) e a média
de salário computada pela função AVG(SALARIO).

     Nesses casos, é necessário agrupar as tuplas que possuem o mesmo
valor de um ou mais atributos, chamados atributos de agrupamento e,
então, aplicar a função de agregação a cada grupo de forma indepen-
dente. SQL possui a cláusula GROUP BY para este propósito (Elmasri e
Navathe, 2018). Esta cláusula especifica o grupo de atributos, que tam-
bém deveria aparecer na cláusula SELECT, de modo que o valor resul-
tante da aplicação da função a um grupo de tuplas apareça juntamente
com o valor do(s) atributo(s) de agrupamento.

     Algumas vezes, deseja-se obter os valores de funções agregadas ape-
nas para grupos que satisfazem certas condições. Na consulta a seguir,
necessita-se que, para cada projeto em que mais de dois funcionários
trabalhem, obtenha-se o número do projeto, o nome do projeto e o número
de funcionários que trabalham nele.




88                                                                    Banco de dados
          Exemplo 18 – Funções de agregação com agrupamento atendendo a uma condição


                                 SELECT NUMPROJ, NOMEPROJ, COUNT(*)
                                 FROM PROJETO P, TRABALHA_EM TE
                                 WHERE P.NUMPROJ = TE.NPROJ
                                 GROUP BY NUMPROJ, NOMEPROJ
                                 HAVING COUNT(*) > 2


    SQL possui uma cláusula denominada HAVING, que funciona em con-
junto com GROUP BY, para este propósito (Elmasri e Navathe, 2018).
HAVING impõe uma condição aos grupos de tuplas associados com
cada valor de atributo de agrupamento, apenas os grupos que satisfa-
zem a condição são obtidos como resultado da consulta.

    Linguagem de manipulação de dados (do inglês, Data Manipulation

adicionar, excluir e alterar as tuplas da tabela (Silberschatz, Korth e
Sudarshan, 2020). Em SQL, há três comandos para modificar a instân-
cia do banco de dados: INSERT, DELETE e UPDATE. De maneira resu-
mida, INSERT é usado para adicionar uma tupla à relação. Observe a
inserção no exemplo 19.

usada em um comando SELECT para consultas. Contudo, no comando
DELETE, essa cláusula determina uma condição para selecionar as tuplas
que serão removidas.

                           DELETE FROM FUNCIONARIO
                           WHERE NUMDEP IN (SELECT NUMDEP
                                            FROM DEPARTAMENTO
                                            WHERE NOMEDEP = ‘Pesquisa’);


     O comando UPDATE é usado para modificar valores de atributos de
uma ou mais tuplas selecionadas (Silberschatz, Korth e Sudarshan,
2020). Como ocorre no comando DELETE, uma cláusula WHERE no
comando UPDATE seleciona as tuplas a serem modificadas. Uma cláu-
sula adicional SET especifica os atributos a serem modificados e seus
novos valores.

4 Visões em SQL
    Uma visão em SQL é uma tabela virtual derivada de outras tabelas.
Ela exibe dados de uma ou mais tabelas reais, mas não armazena fisi-
camente (Elmasri e Navathe, 2018). O comando para especificar uma
visão é o CREATE VIEW. A visão recebe um nome, uma lista de nomes
de atributos e uma consulta especificando o conteúdo da visão.

                                Exemplo 22 – Comando CREATE VIEW


                                 CREATE VIEW VW_FUNCIONARIO AS
                                 SELECT NOME, SOBRENOME, ENDER
                                 FROM FUNCIONARIO


    Uma visão pode ser descartada, para isso, basta utilizar o comando
DROP VIEW. O próximo exemplo utiliza o comando DROP VIEW para eli-
minar a VIEW VW_FUNCIONARIO.

                                Exemplo 23 – Comando CREATE VIEW


                                    DROP VIEW VW_FUNCIONARIO
