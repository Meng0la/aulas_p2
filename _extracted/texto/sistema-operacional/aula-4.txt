1 Serviços de DHCP (dynamic host
configuration protocol)
     Nesta seção, você aprenderá como configurar um serviço de DHCP
criando escopos de trabalho.


1.1 O que é DHCP?

     Em um ambiente pequeno, é normal que um técnico mapeie o IP de
cada equipamento manualmente, criando o IP “192.168.0.100”, por exem-
plo. Dessa forma, pode-se criar uma rede de computadores. Mesmo as-
sim, o processo é repetitivo e moroso. A cada novo equipamento na rede,
é necessário fixar o IP. Esta ainda é uma realidade em muitas redes do
Brasil. Em um ambiente corporativo com diversos equipamentos, a ação
de fixar manualmente o IP torna-se impossível. O protocolo DHCP desem-
penha uma função importante na infraestrutura de uma rede. Trata-se
do principal meio de distribuição de informações sobre as configurações
dos serviços de rede para os clientes, entregando também outras infor-
mações sobre os serviços (THOMPSON, 2017).

     O DHCP também é importante para dispositivos móveis, como o
celular, que está em constante mudança de rede. Esse serviço oferece
diversas informações complexas de rede para os usuários (dispositi-
vos), sem que ele necessite entender de redes de computadores ou
como configurá-las.

     O serviço do DHCP pode ser configurado tanto no ambiente gráfico
como na interface de linha de comando. Neste material, demonstrare-
mos como instalar o serviço.

                                                                                                                                                                                                                                         figurada em horas ou dias.                                                                                                                                                                                                                                          usuários conectados através de cabos, e três dias para usuários que
                                                                                                                                                                                                                                         utilizam Wi-Fi.                                                                                                                                                                                                                                                   rede o pacote de DHCPDISCOVER.                                                                                                                                                                                                                                                   (computador com função de DHCP).

                                                                                                                                                                                                                                                  DHCPOFFER, contendo um endereço.

                                                                                                                                                                                                                                             3. O computador recebe o pacote DHCPOFFER e transmite o
                                                                                                                                                                                                                                                  DHCPREQUEST, contendo um identificador.                                                                                                                                                                                                                                                   rede possuir outros servidores DHCP, como acontece essa etapa

                                                                                                                                                                                                                                                  po de resposta do pacote DHCPDISCOVER, ou seja, a decisão do

                                                                                                                                                                                                                                                  garantirá que o servidor de DHCP esteja mais próximo. 1.3 Renovação do IP

     Quando você configura o serviço de DHCP no servidor, uma das eta-
pas é definir a validade daquele IP para o cliente, que pode ser conce-

feita sem a intermediação do usuário, totalmente em segundo plano. O
cliente manda o pacote DHCPREQUEST para a rede, o servidor DHCP
identifica que aquele pacote pertence a ele e devolve o DHCPACK com
as informações para a atualização do cliente.
